How to use it · idea → running agent

The flow

  • Spec it spec-driven-development
    “Set up the spec for a customer-support agent.” → writes the constitution + feature trio into docs/specs/.
  • Design & plan brainstorming writing-plans
    Refines the design in chunks you approve, then breaks it into bite-sized tasks — each with a verify step.
  • Build it subagent-driven-development TDD
    “Execute the plan.” → a fresh agent per task, tests first, two-stage review between tasks.
  • Scaffold the agent agentbase-wizard
    “Scaffold this as a GreenNode agent with LangGraph.” → project + memory, identity & LLM access wired.
  • Deploy it agentbase-deploy
    “Deploy to GreenNode.” → builds & pushes the image, creates the runtime, verifies the endpoint.
  • Operate it agentbase-monitor agentbase-teardown
    “Show my agent's logs.” → logs, metrics, scaling — and one-shot cleanup when you're done.

Throughout: the agent updates the related spec whenever code changes — so docs and code never drift. No commands to memorize — skills trigger from what you say.
